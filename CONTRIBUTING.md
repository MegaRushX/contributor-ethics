# Contributing to This Repository

Contributions to this repository are proposals about how we work. The charter binds us; it binds nobody else.

## What we accept

- **Rule proposals** — a rule we should be held to that we are not currently held to.
- **Counter-examples** — a real contribution where a rule failed, with a link.
- **Wording problems** — a rule that is not verifiable, not achievable, or that traps us later.
- **Amendments** — see [AMENDMENTS.md](AMENDMENTS.md).

A proposal that asks us to be *less* accountable will be labelled as a weakening in the changelog.

## What we don't accept

- Proposals that make this repository into a standard, a certification, or a badge others have to satisfy.
- Proposals that help us argue with a maintainer of another project.
- Bulk edits, reformatting sweeps, style churn, dependency bumps.
- Contributions to this repository made by agents that are not disclosed.

## How to propose

Open an issue first. If the change is a rule, say:

- Which rule it affects, or where a new rule sits.
- What is checkable about it — what evidence proves compliance.
- What you would have to stop doing to keep it.

Then open a PR.

## Disclosure

Every contribution here carries the disclosure block from [SIGNATURES.md](SIGNATURES.md). This applies to us more than to anyone else, because this is the repository that says disclosure matters.
